Does each heuristic help?

Removing one feature and refitting fusion tests its incremental contribution. Features are correlated, so effects need not add up.

What the benchmark establishes

These are static, transductive missing-edge experiments. All paper features are available, but selection, fusion and test links are hidden from the graph.

Each test set has equal numbers of hidden links and sampled non-edges. Scores describe this candidate set; they do not measure future citations or an all-pairs recommender.

Evidence behind the score

A zero common-neighbor count makes CN, Jaccard, Adamic-Adar and Resource Allocation zero. Embeddings and degree-based Preferential Attachment can still provide a signal.

Fusion score decomposition

Transformed features are standardized using fusion-fitting pairs only. Each contribution is standardized feature × learned coefficient. This explains the calculation, not a causal effect.

80%Build the graph
Train GAE, VGAE and DeepWalk. Compute neighborhoods.
5%Select a checkpoint
Choose encoder epochs using selection AP.
5%Fit fusion
Fit a scaler and logistic regression on hidden pairs.
10%Measure performance
Evaluate all methods on the same untouched pairs.
No held-out positive edge enters message passing or heuristic computation. Negative pairs come from the complement of the full original graph and are disjoint across evaluation partitions.

Local structure + latent structure

VGAE learns a distribution of sixteen-dimensional representations from paper attributes and the training graph. At evaluation, the dot product of mean embeddings scores a pair.

Fusion combines that score with Common Neighbors, Jaccard, Adamic-Adar, Resource Allocation and Preferential Attachment. Logistic regression learns six coefficients on a separate labeled partition.

GAE and DeepWalk are independently implemented existing methods. Heuristics-only and VGAE-score-only regression check whether gains require both sources.

Research question, not a promised win

The question is whether these simple features add information to VGAE on each network. Five paired runs, feature-removal ablations and zero-common-neighbor analysis help distinguish consistent gains from a favorable example.

This extends the selected VGAE base paper. Combining heuristics and embeddings is established prior work; the project contribution is a controlled, inspectable study.
